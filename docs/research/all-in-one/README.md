# All-in-one platform research (2026-11-06)

Purpose: what commercial all-in-one small-business platforms (CRM, conversations, scheduling,
marketing, money, automation) ship, so the template can offer the same. Every row in these files
cites a URL and is labeled OBSERVED (read on the cited page) or INFERRED. "Not confirmed" means
no primary page could be reached; do not treat it as fact. The consolidated plan built from these
files is `docs/plan/all-in-one-feature-plan.md`.

| File | What it holds |
|---|---|
| `00-template-today.md` | What the template can do today, from code, with file paths. The "today" column of the gap analysis. |
| `01-highlevel.md` | HighLevel feature inventory, the spine of the reference set: account structure, CRM, conversations, calendars, workflows (triggers and actions), marketing, sites, reputation, payments, reporting, AI, pricing. |
| `02-keap-thryv-zoho-hubspot-starter.md` | Keap, Thryv, Zoho small-business stack, HubSpot Starter: what differs from HighLevel, the common core, pain points. |
| `03-vendasta-podium-birdeye.md` | Local-business inbox and reputation platforms: unified inbox, review requests and AI replies, listings, text to pay, AI receptionists, per-location pricing. |
| `04-professional-services.md` | TaxDome, Canopy, Clio, Karbon, HoneyBook: client portal, document requests, e-signature with KBA, engagements, recurring invoicing, time tracking, trust accounting. |
| `05-appointments.md` | Fresha, Vagaro, Mangomint, Square Appointments, Boulevard: service time components, resources, deposits and no-show policies, waitlist, checkout and POS, memberships, commissions. |
| `06-field-service.md` | Jobber, Housecall Pro, ServiceTitan, Workiz: request to quote to job to visit to invoice spine, dispatch, job costing, service plans, client hub, AI receptionists. |
| `07-real-estate-and-retail.md` | Follow Up Boss, Lofty, BoldTrail; Square business suite, Toast: lead routing modes, speed to lead, loyalty, customer directory from transactions. |
| `08-automation-builders-and-ai.md` | Twelve automation builders catalogued, a normalized taxonomy with table-stakes counts, 25 common recipes, how every vendor configures AI, and the recommendation for automation on an agent runtime. |
| `09-conversations-and-channels.md` | Inbox features users see, the compliance and provider reality per channel (10DLC, toll-free, WhatsApp Cloud API, email authentication, Messenger and Instagram, voice), provider comparison. |
| `10-calendars-and-booking.md` | Event types, availability model, booking experience, lifecycle, sync, team and resources, reporting, and a normalized data model drawn from Cal.com. |
| `11-money.md` | Quotes, documents and e-signature, invoices, payments, products and subscriptions, checkout, accounting sync, reporting, and a normalized data model drawn from Stripe. |
| `12-marketing.md` | Email, SMS, segmentation, forms, pages, reputation, social, attribution, compliance, with table-stakes tiers. |
| `13-user-reviews-and-switching.md` | What users praise, complain about and switch over across 17 products; must-haves per business family; what makes a system of record trusted; onboarding and churn. |

Method limits shared by every file: the web-search budget ran out partway through each agent's
run, so most evidence came from direct fetches of official help centers, docs and pricing pages;
G2, Capterra and Reddit refused automated fetches, so forum-sourced pain points are thin or
second-hand. Items listed as "not confirmed" at the end of each file are the follow-up list.
